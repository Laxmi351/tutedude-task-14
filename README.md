
# TuteDude Task 14 - JavaScript Loops

## Project Description
This project demonstrates JavaScript loops through different number-based operations and mathematical calculations.

## Technologies Used
- HTML5
- CSS3
- JavaScript

## Concepts Covered
- For Loop
- While Loop
- Conditional Statements
- Arithmetic Operators
- Prime Number Checking
- Multiplication Table
- Factors of a Number

## Features
1. Sum of first N natural numbers.
2. Multiplication table of a number.
3. Check whether a number is prime.
4. Print all factors of a number.
5. Calculate the sum of digits.
6. Check Armstrong number.

## Learning Objective
To understand JavaScript loops, conditions, and logical problem-solving.

## How to Run
1. Download or clone the repository.
2. Open index.html in a browser.
3. Press F12 and open the Console tab to see the output.
